# RELAY OCR

cung cấp pipeline OCR phiếu chỉnh định rơ-le cho các trạm biến áp.

## Cài đặt

```bash
git clone https://github.com/provincevu/Relay_OCR.git
cd Relay_OCR

# Cài dependencies
pip install -r requirements.txt
```
