# Tools

Nhóm này chứa công cụ nghiên cứu, tạo ground truth, đánh giá và xem kết quả.

| Tệp                            | Trách nhiệm                                   |
| ------------------------------ | --------------------------------------------- |
| `evaluate_table_01.py`         | So sánh prediction TABLE 01 với ground truth. |
| `experiment_detector_page3.py` | Thử nghiệm nhiều cấu hình text detector.      |
| `serve_page_n_predictions.py`  | Phục vụ giao diện xem prediction page 3+.     |
| `serve_rule_induction.py`      | Phục vụ giao diện xác nhận Rule Induction.    |

Các tệp trong nhóm này hỗ trợ quy trình, không phải thành phần bắt buộc của pipeline OCR chính.
